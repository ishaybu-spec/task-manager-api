# Task Manager API

## תיאור הפרויקט

זהו שרת לניהול משתמשים ומשימות.

השרת מאפשר למשתמשים להירשם ולהתחבר, ליצור משימות ולנהל אותן.

לכל משתמש יש גישה רק למשימות השייכות אליו.

הפרויקט כולל מערכת אימות משתמשים, הצפנת סיסמאות, בדיקת נתונים, טיפול בשגיאות והגבלת מספר הבקשות.

## טכנולוגיות

הפרויקט משתמש בטכנולוגיות הבאות:

```text
Node.js
Express
Sequelize
SQLite
JWT
bcrypt
dotenv
express-rate-limit
```

## התקנה

לאחר הורדת הפרויקט, יש להתקין את כל החבילות הנדרשות.

```bash
npm install
```

## הגדרת משתני סביבה

יש ליצור בתיקיית הפרויקט קובץ בשם:

```text
.env
```

בתוך הקובץ יש להגדיר את המשתנים הבאים:

```env
PORT=3000
JWT_SECRET=your_secret_here
DB_STORAGE=./database.sqlite
```

יש להחליף את הערך של משתנה הסוד במפתח סודי.

אין להעלות את קובץ הסביבה ל־GitHub.

בפרויקט קיים גם קובץ לדוגמה בשם:

```text
.env.example
```

הקובץ מציג את משתני הסביבה הנדרשים להפעלת הפרויקט.

## הפעלת השרת

להפעלת השרת במצב פיתוח:

```bash
npm run dev
```

להפעלת השרת במצב רגיל:

```bash
npm start
```

לאחר הפעלת השרת ניתן לגשת אליו בכתובת:

```text
http://localhost:3000
```

## מערכת המשתמשים

המערכת מאפשרת לבצע שתי פעולות עיקריות.

### הרשמת משתמש

סוג הבקשה:

```text
POST
```

כתובת:

```text
/api/auth/register
```

דוגמה לגוף הבקשה:

```json
{
    "name": "John",
    "email": "john@example.com",
    "password": "123456"
}
```

### התחברות

סוג הבקשה:

```text
POST
```

כתובת:

```text
/api/auth/login
```

דוגמה לגוף הבקשה:

```json
{
    "email": "john@example.com",
    "password": "123456"
}
```

לאחר התחברות מוצלחת מתקבל אסימון אימות.

## אימות

המערכת משתמשת באסימון JWT לצורך אימות המשתמש.

בכל בקשה מוגנת יש לשלוח את האסימון בכותרת הבקשה.

```text
Authorization: Bearer <token>
```

## ניהול משימות

### יצירת משימה

סוג הבקשה:

```text
POST
```

כתובת:

```text
/api/tasks
```

דוגמה לגוף הבקשה:

```json
{
    "title": "Learn Node.js",
    "description": "Study Express and Sequelize",
    "status": "pending",
    "dueDate": null
}
```

### קבלת כל המשימות

סוג הבקשה:

```text
GET
```

כתובת:

```text
/api/tasks
```

הפעולה מחזירה את כל המשימות של המשתמש המחובר.

### קבלת משימה לפי מזהה

סוג הבקשה:

```text
GET
```

כתובת:

```text
/api/tasks/:id
```

הפעולה מחזירה משימה מסוימת לפי המזהה שלה.

### עדכון משימה

סוג הבקשה:

```text
PUT
```

כתובת:

```text
/api/tasks/:id
```

הפעולה מעדכנת משימה קיימת.

### מחיקת משימה

סוג הבקשה:

```text
DELETE
```

כתובת:

```text
/api/tasks/:id
```

הפעולה מוחקת משימה קיימת.

כל הפעולות הקשורות למשימות דורשות אימות.

## סטטוסים של משימות

המערכת מאפשרת להשתמש בשני סטטוסים:

```text
pending
completed
```

## אבטחה

המערכת כוללת את אמצעי האבטחה הבאים:

* הצפנת סיסמאות באמצעות bcrypt.
* אימות משתמשים באמצעות JWT.
* הרשאות גישה לפי המשתמש המחובר.
* בדיקת תקינות של נתוני הבקשות.
* שימוש במשתני סביבה עבור מידע רגיש.
* הגבלת מספר הבקשות.
* טיפול מרכזי בשגיאות.

כל משתמש יכול לצפות, לעדכן ולמחוק רק את המשימות השייכות אליו.

## מסד הנתונים

הפרויקט משתמש במסד הנתונים SQLite.

Sequelize משמש לניהול הגישה למסד הנתונים.

מסד הנתונים נוצר באופן אוטומטי בעת הפעלת השרת.

שם קובץ מסד הנתונים:

```text

```

קובץ מסד הנתונים אינו מועלה ל־GitHub.
